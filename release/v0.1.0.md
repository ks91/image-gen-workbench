## Image Gen Workbench v0.1.0

The first release of a local image generation and editing workbench powered by Qwen-Image-2.1, with a browser interface in English and Japanese.

### Highlights

- Generate 1–8 images per submission and refine selected images with text instructions.
- Browse paginated history, compare results, keep favorites and notes, and reuse settings.
- Delete unused results and uploads, with protection for images referenced by later edits.
- Choose whether PNG downloads include prompts and generation settings in the Settings dialog.
- Inspect saved PNG generation metadata with `./inspect-png IMAGE.png`.
- Start the server and open a browser with `./run`; check the version with `./run --version`.
- Limit queued work, uploads, and managed storage, and display notifications above the workspace.
- Licensed under GPL-3.0-or-later.

### Compatibility Notes

- Python 3.12 or later is required; Python 3.12 is recommended on macOS.
- The reference hardware is an Apple M2 Ultra with 128 GB unified memory. Other hardware has not been verified. Quantization and CPU offloading are not implemented.
- Model weights are downloaded on first generation; substantial memory and disk space are required.
- This is a personal, loopback-only application without authentication. Do not expose it to untrusted users or networks.
- Uploads support PNG, JPEG, and WebP. Export metadata is included by default; turn it off in Settings before sharing private prompts.

### Validation

- 55 Python tests and 16 JavaScript tests pass (71 total).
- CLI checks verify the exact version output and that version queries do not start a server or create a data directory.
- Package metadata is checked against the same version source used by the CLI.
- The current interface was inspected in Safari; a screenshot is included in the README.
- No new full-model inference run was performed specifically for this release.

### Install

```sh
git clone --branch v0.1.0 https://github.com/ks91/image-gen-workbench.git
cd image-gen-workbench
python3.12 setup.py
./run --version
./run
```

To try the interface without downloading model dependencies, use `python3.12 setup.py --ui-only` and `./run --demo`.

Existing checkout users should stop the server and back up their data directory before switching to the release tag and rerunning setup. The default `data/` directory contains saved images and history; keep it when updating.
